# ⚡ Swiftgram / Telegram-iOS Mod (Ghost Mode + Anti-Delete + Premium + NFT StarGifts)

Модифицированный клиент Telegram для iOS на базе официального открытого исходного кода Telegram-iOS / Swiftgram с автоматической облачной сборкой в **GitHub Actions** (Mac не требуется, сборка запускается в один клик прямо с Windows).

---

## 🌟 Внедренные функции и возможности

### 1. 🤫 Секретное мод-меню
- **Как открыть:** Зажмите пальцем нижнюю вкладку **«Чаты»** в панели навигации ровно на **5 секунд**.
- Сработает приятная тактильная виброотдача (Haptic Feedback) и на экране появится удобное всплывающее меню со всеми настройками и переключателями.
- Все параметры сохраняются автоматически в `UserDefaults` устройства.

### 2. 👻 Режим призрака (Ghost Mode) — 4 независимых пункта:
- **Пункт 2.1. Скрытие онлайн-статуса:** Полностью блокирует отправку сетевого запроса `account.updateStatus(offline: false)`. При входе и использовании приложения ваш статус в сети не обновляется на «в сети».
- **Пункт 2.2. Чтение сообщений без отметки:** Блокирует отправку запросов `messages.readHistory`, `channels.readHistory`, `messages.readEncryptedHistory` и `messages.readMessageContents`. Входящие сообщения отмечаются прочитанными локально у вас (счетчик сбрасывается), но собеседник **не видит** две синие галочки прочтения.
- **Пункт 2.3. Отключение статуса набора текста:** Блокирует отправку `messages.setTyping` и статусов записи голосовых сообщений/видеокружков. Собеседник никогда не увидит, что вы что-то печатаете или записываете.
- **Пункт 2.4. Отложенная отправка сообщений (Таймер задержки):** Позволяет задать любое количество секунд задержки (например: 5, 10, 30 сек; 0 — выключено). При обычном нажатии на кнопку отправки сообщение задерживается на выбранное время. Вы всегда успеете передумать, отредактировать или удалить сообщение до того, как оно реально улетит в сеть.

### 3. 🗑️ Анти-удаление сообщений (Anti-Delete)
- Перехватывает события удаления сообщений (`DeleteMessages` и `DeleteMessagesWithGlobalIds` в локальной базе `Postbox`).
- Если собеседник удаляет сообщение у себя и у вас («удалить для всех»), сообщение **не удаляется** из вашей базы данных, а сохраняется в чате с добавлением пометки `[Удалено]`.

### 4. ⭐ Локальный Telegram Premium
- Перехватывает свойства `isPremium` в моделях пользователя (`TelegramUser`, `EnginePeer`, `Peer`).
- Разблокирует премиальные визуальные функции интерфейса, значки, премиум-эмодзи и реакции без необходимости оформления платной подписки.

### 5. 🎁 Конструктор NFT-подарков (StarGift.Unique) в профиле
- Внутри мод-меню доступен раздел **«Конструктор NFT-подарков»**.
- Позволяет выбрать любую 3D-модель (Durov's Cap, Plush Pepe, Diamond Ring, Gold Trophy, Cyber Skull, Imperial Crown и др.), задать стиль фона, узор и уникальный номер (например, #777).
- Созданные подарки сохраняются и автоматически внедряются в список подарков вашего профиля (`ProfileGiftsContext`).
- Подарки отображаются во вкладке «Подарки» вашего профиля и могут надеваться как статус.

## 🚀 Как собрать готовый .IPA файл в GitHub Actions (Пошагово)

Вам не нужен компьютер Mac — всё компилируется в облаке на серверах GitHub Actions.

### Шаг 1. Создайте свой репозиторий на GitHub
1. Зайдите на [github.com](https://github.com) и войдите в свой аккаунт.
2. Нажмите **New repository** (Создать новый репозиторий).
3. Назовите его, например, `TelegramMod` и выберите видимость **Private** (или **Public**).
4. Нажмите **Create repository**.

### Шаг 2. Загрузите файлы из этой папки в репозиторий
В терминале в этой папке выполните команды:
```bash
git init
git add .
git commit -m "Initial commit of Telegram iOS Mod"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/TelegramMod.git
git push -u origin main
```
*(Либо просто перетащите файлы `patcher.py`, `ModMenu.swift`, `ModNFTGiftsManager.swift`, `build_configuration.json` и папку `.github` через браузер на странице репозитория).*

### Шаг 3. Запустите облачную сборку
1. В вашем репозитории на GitHub перейдите во вкладку **Actions**.
2. В левой колонке нажмите на воркфлоу **Build Modded Telegram-iOS IPA**.
3. Справа нажмите кнопку **Run workflow**.
4. Нажмите зеленую кнопку **Run workflow**.

GitHub автоматически выделит виртуальный сервер macOS, скачает исходники, применит патчи нашего мода и соберет `.ipa` файл с помощью Bazel.

### Шаг 4. Скачайте готовый .IPA файл
1. Когда сборка завершится (появится зеленая галочка), нажмите на неё.
2. В самом низу страницы в блоке **Artifacts** появится архив **TelegramMod-unsigned-ipa**.
3. Нажмите на него и скачайте на ваш компьютер. Распакуйте архив — внутри будет готовый файл `Telegram.ipa`.

## 📲 Как установить .IPA на iPhone / iPad через Sideloadly

1. Скачайте бесплатную программу **[Sideloadly](https://sideloadly.io/)** для Windows.
2. Подключите ваш iPhone к компьютеру через USB-кабель (если телефон спросит «Доверять этому компьютеру?», нажмите «Доверять»).
3. Запустите Sideloadly:
   - В поле **Apple ID** введите ваш Apple ID (используется только для локальной бесплатной подписи приложения для вашего устройства).
   - Перетащите файл `Telegram.ipa` в окно Sideloadly.
   - Нажмите кнопку **Start**.
4. После завершения установки на iPhone появится иконка Telegram.
5. На iPhone откройте: **Настройки** -> **Основные** -> **VPN и управление устройством** -> выберите ваш Apple ID и нажмите **«Доверять»**.
6. Откройте Telegram, авторизуйтесь и зажмите вкладку **«Чаты»** внизу на 5 секунд для открытия мод-меню!
